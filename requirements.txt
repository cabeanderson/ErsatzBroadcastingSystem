# ErsatzTV Scheduling Framework — Python dependencies
#
# THE SCHEDULER ITSELF NEEDS NOTHING.
#
# Everything under channels/, library/, logic/, engines/, core/ and scheduling/
# — the whole scheduling framework, and the simulator that exercises it — runs
# on the Python standard library (3.10+). `pip install -r requirements.txt`
# is a no-op, and that is deliberate: the framework is imported by ErsatzTV's
# own scripting runtime, and adding dependencies there is not always yours to
# do.
#
# The one binding it needs, `etv_client`, ships INSIDE ErsatzTV. It is not on
# PyPI and must not be pip-installed:
#
#   * In the ErsatzTV container (production):
#       already importable from ErsatzTV's scripting runtime — nothing to do.
#       https://github.com/ErsatzTV/ErsatzTV
#
#   * On a dev machine (simulator / tests, for planning channels):
#       no real etv_client is required. The repo ships an in-memory mock,
#       installed automatically on `import scripts.testing`. See the README
#       section "Local channel planning".
#
# ----------------------------------------------------------------------------
# THE OFFLINE TOOLING DOES NEED THINGS.
#
# scripts/filler and scripts/nfo are workstation tools for acquiring, cutting
# and tagging interstitials. They are not imported by the scheduler and are not
# needed to run a channel. Install these only if you use them:
#
#   lxml               scripts/nfo/normalize_tag_case.py
#                      pip install lxml
#
#   faster-whisper     scripts/filler/analyze_spots.py (transcribes spots)
#                      pip install faster-whisper
#
# And two external binaries, which pip cannot provide — install them with your
# system package manager and make sure they are on PATH (or point ETV_FFMPEG /
# ETV_FFPROBE at them; see scripts/config.py):
#
#   ffmpeg, ffprobe    scripts/filler/{analyze_spots,contact_sheet,
#                      dedupe_bumpers,file_us_commercials,split_reels}.py
